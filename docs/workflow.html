How a question becomes an answer

One question, followed end to end. The point of the picture is the colour: everything that produces a number is code, and everything the model touches is words.

Three things that can go wrong, and what happens

  • The model states a number that isn't in the result. The check catches it and the figure is flagged on screen, next to the answer, where you cannot miss it.
  • The model answers without calling a tool at all. Then it invented everything. The server throws the reply away and answers from rules instead, and says that it did.
  • The model is slow or unreachable. The same rules-based path answers instantly. Same tools, same numbers, plainer wording. There is a button for it, and it doubles as the control: if the two ever disagree, the model is wrong.

The rules-based path replaces only the two amber boxes. Everything blue runs exactly as it does above, which is why the numbers come out identical.
